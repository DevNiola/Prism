Start the CLI's local HTTP and WebSocket server. Keep this process running while clients connect to the dashboard, `/api/trace/:tx_hash`, or `/ws`. Trace requests need access to the selected network's RPC endpoint.

## Usage

```bash
grat serve [OPTIONS]
```

| Option | Default | Behavior |
| --- | --- | --- |
| `-p, --port <PORT>` | `8080` | TCP port to listen on. |
| `--host <HOST>` | `127.0.0.1` | IP address to bind to. |
| `-n, --network <NETWORK>` | `testnet` | Network to use for traces. |
| `--rpc-url <URL>` | Selected network's RPC URL | Override the RPC endpoint. |
| `--no-cache` | Off | Bypass the local cache for network data. |

## Example

```bash
grat serve --host 127.0.0.1 --port 9090 --network testnet
```

Open `http://127.0.0.1:9090` in your browser or connect your WebSocket client to `ws://127.0.0.1:9090/ws`.

See the [global CLI options](/cli-reference#global-flags) for shared defaults. Use `--help` (`-h`) for command help or `--version` (`-V`) for the CLI version.
