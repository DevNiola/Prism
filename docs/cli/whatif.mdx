Load a hypothetical transaction's patch file and report the patch count. The current CLI implementation reads and validates the patches and can save the session metadata. Simulation is handled separately by the core debugger.

## Usage

```bash
grat whatif <TX_HASH> [OPTIONS]
```

| Argument or option | Default | Behavior |
| --- | --- | --- |
| `<TX_HASH>` | Required | Transaction hash to associate with the session. |
| `--modify <PATH>` | Omitted | Load a JSON array of patches from a file. |
| `--output <FORMAT>` | `human` | Set the status output format. |
| `--save <PATH>` | Omitted | Write session metadata and patches as JSON. |

## Example

Save this array as `patches.json`. Patch types are `ModifyArgument`, `ModifyLedgerEntry`, `ModifyResourceLimits`, and `ModifyAuth`.

```json
[
  {
    "ModifyResourceLimits": {
      "cpu_limit": 100000000,
      "memory_limit": null
    }
  }
]
```

Set `TX_HASH` to the hash you want to associate with the session, then run:

```bash
grat whatif "$TX_HASH" --modify patches.json --output json --save whatif.json
```

See the [global CLI options](/cli-reference#global-flags) for shared defaults. Use `--help` (`-h`) for command help or `--version` (`-V`) for the CLI version.
