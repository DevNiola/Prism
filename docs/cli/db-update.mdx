Load the latest taxonomy available to the local loader and report the number of error definitions. The command's download progress messages currently simulate a refresh. Automatic taxonomy update checks run separately at CLI startup and can be disabled with `--offline`.

## Usage

```bash
grat db update [OPTIONS]
```

This subcommand has no positional arguments or command-specific options. The global `--output` option defaults to `human`. Use `json` for a status object with an entry count. The accepted `compact` and `short` formats follow the human output path here.

## Example

```bash
grat db update --output json
```

See the [global CLI options](/cli-reference#global-flags) for shared defaults. Use `--help` (`-h`) for command help or `--version` (`-V`) for the CLI version.
