Prism's CLI binary is named `grat`. Use Bash and install Git and the stable Rust toolchain with [rustup](https://rustup.rs/). The CLI build does not require Node.js or pnpm. For web or extension development, install Node.js 20 or later and pnpm 9.

## Clone and build

```bash Terminal
git clone https://github.com/DevNiola/Prism.git
cd Prism
cargo build --release -p grat-cli
```

<Note>
  A clean checkout can currently fail at dependency resolution because the workspace requests the `next` feature from `stellar-xdr` 30. If you already have `grat` installed, use `grat` in place of `./target/release/grat` below.
</Note>

## Verify the CLI with a fixture

From the repository root, decode the `resultXdr` value from `tests/fixtures/transactions/budget_exceeded.json`:

```bash Terminal
./target/release/grat decode --raw 'AAAAAAAAAGT/////AAAAAQAAAAAAAAAB////+wAAAAA=' --output json
```

The JSON report should contain `"error_name": "RawXdr"` and say that it decoded 32 bytes. This confirms the CLI can read the fixture's base64 XDR without looking up a transaction. The fixture hash is synthetic.

## Decode a transaction by hash

Paste the hash of an available failed transaction when prompted. Use `--network mainnet` for a mainnet transaction.

```bash Terminal
read -r -p 'Failed testnet transaction hash: ' tx_hash
./target/release/grat decode "$tx_hash" --network testnet
```

Review the report for the error name, explanation, and any suggested fixes. The [decode command reference](./cli/decode) covers output formats and other flags.
