## Report a vulnerability

1. Email the project maintainers privately. Keep vulnerability details out of public issues and pull requests.
2. Include the affected version or commit, the affected component, the impact, and enough detail for the maintainers to reproduce the issue. Remove credentials and personal data from attachments.
3. Keep follow-up and any disclosure timing in the private email thread with the maintainers.

The repository maintains the [security policy](https://github.com/DevNiola/Prism/blob/main/SECURITY.md).

## Security practices

- Grat performs read-only diagnostics and never handles private keys or signs transactions.
- Transaction replay runs in an isolated local sandbox without network access.
- Grat validates external inputs such as XDR and WASM metadata before processing them.

## Automated scanning

GitHub Actions audits Rust dependencies with `cargo-audit` against RustSec and JavaScript dependencies with `pnpm audit`, which enforces high and critical severity findings. CodeQL analyzes pull requests and runs weekly. Trivy scans filesystem configuration, secrets, and container manifests. High-severity findings block pull requests from merging. [Security workflow](https://github.com/DevNiola/Prism/blob/main/.github/workflows/security.yml)
