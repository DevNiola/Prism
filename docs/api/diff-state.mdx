---
title: "Diff ledger state"
description: "Read the ledger changes recorded during a replay."
---

The Fastify server has no standalone state diff route. Run `grat --network testnet serve` and use the CLI bridge's `GET /api/trace/:tx_hash`. Supply a transaction hash in the path and leave the request body empty.

```bash
curl --fail-with-body "http://localhost:8080/api/trace/${TX_HASH}" |
  jq '.state_diff.entries'
```

HTTP 200 returns a JSON execution trace. The `state_diff.entries` array contains ledger entry keys, change types, and before and after values where available. Replay failures return HTTP 500 with plain text.

Use `grat --network testnet --output json diff state "$TX_HASH"` to get the diff directly.
