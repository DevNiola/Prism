## Cache storage

| Milestone | Status |
| --- | --- |
| Calculate total cache size across the cache directory. | <Badge color="green">Done</Badge> |
| Trigger least-recently-used eviction when a write would exceed the size limit. | <Badge color="green">Done</Badge> |
| Evict the oldest files first by last access time, falling back to modification time. | <Badge color="green">Done</Badge> |
| Refresh access time on reads so eviction accounts for recent use. | <Badge color="green">Done</Badge> |
| Cover the aggregate size limit after evictions with unit tests. | <Badge color="green">Done</Badge> |
| Verify the cache change with the Rust test suite. | <Badge color="green">Done</Badge> |
