# Grat VS Code Extension

See the [VS Code extension guide](interfaces/vscode.mdx) for source installation, screenshots, the transaction decode workflow, and troubleshooting.

The extension source lives in [`extensions/vscode/`](../extensions/vscode/). During development, run `pnpm --filter grat-vscode watch` from the repository root to rebuild on save. Reload the Extension Development Host to use the rebuilt extension.
