## Install the CLI

Install the CLI from the repository with a current stable Rust toolchain. The Cargo package is named `grat-cli` and installs the `prism` executable.

```bash
cargo install --git https://github.com/DevNiola/Prism.git --branch main grat-cli
prism --version
```

## Build from a checkout

```bash
git clone https://github.com/DevNiola/Prism.git
cd Prism
cargo build --release -p grat-cli
./target/release/prism --version
```

For web or server development, also install Node.js and pnpm as described in the [contributing guide](/contributing).

## Accessing RPC

Prism requires a Soroban RPC endpoint to fetch transaction data.

- **Testnet and Mainnet** use public endpoints by default.
- **Custom endpoints** can be set with the `--rpc-url` flag or the `SOROBAN_RPC_URL` environment variable.
