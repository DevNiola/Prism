# Grat — Soroban Debugger for VS Code

Use **Grat: Decode Transaction Error** in the VS Code Command Palette to look up a failed testnet transaction and open its JSON report beside the active editor.

The extension requires VS Code 1.95 or later and a `grat` executable on the extension host's `PATH`. See the [VS Code extension guide](../../docs/interfaces/vscode.mdx) for setup, screenshots, provider status, and troubleshooting.
